# 📊 Daily Expense Tracker

A lightweight, privacy-focused, offline-first Web & Mobile Application designed to help users track their daily incomes, expenses, and financial health seamlessly. Built with clean HTML5, CSS3, and modern JavaScript.

Developed with ❤️ by **Newrule Design Studio**.

---

## 🌟 Key Features

- 🔐 **Local Authentication System**: Secure local login with "Remember Me" functionality.
- 🔑 **Self-Service Password Recovery**: Reset forgotten passwords using a personalized 4-digit Recovery PIN.
- 📅 **Date-Indexed Overview**: Dynamic financial metrics including Brought Forward, Income, Expenses, and Closing Balance recalculated automatically per selected date.
- 🛍️ **Multi-Item Expense Entry**: Add multiple expense items with categories and payment methods (DuitNow/QR, Online Banking, Cash, Credit/Debit) in a single batch.
- 📈 **Interactive Analytics**: Visual charts powered by Chart.js showing category breakdowns and Income vs. Expense comparisons.
- 📤 **Share Daily Summary**: Instantly format and share daily transaction summaries directly to WhatsApp or clipboard.
- 💾 **Export & Import Backup (.json)**: Easily backup data to a lightweight `.json` file to transfer across devices or save to Google Drive/Cloud storage.
- 📱 **PWA Ready**: Can be installed on Android and iOS home screens as a Progressive Web App (PWA) with zero server setup required.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (CSS Variables, Flexbox, CSS Grid)
- **Logic**: Vanilla JavaScript (ES6+)
- **Storage**: Browser `localStorage` (100% Client-Side & Offline Support)
- **Data Visualization**: [Chart.js](https://www.chartjs.org/)
